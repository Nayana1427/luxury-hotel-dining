# Royal Palace Hotel Menu Website

## Project Overview

Royal Palace Hotel Menu Website is a responsive Full Stack Development (FSD) mini project developed using HTML, CSS, and JavaScript.

The website provides an attractive hotel homepage and an interactive food menu with separate sections for:

* Starters
* Main Course
* Desserts

Users can browse menu items, add food items to the cart, view the total amount, and place orders.

---

## Features

### Home Page

* Modern hotel landing page
* Luxury hotel theme
* Responsive design
* Navigation to menu sections

### Starters Menu

* Veg Starters
* Egg Starters
* Non-Veg Starters
* Add to Cart functionality

### Main Course Menu

* Roti varieties
* Veg dishes
* Non-Veg dishes
* Dynamic cart updates

### Desserts Menu

* Cakes
* Ice Creams
* Puddings
* Pastries
* Cart support

### Shopping Cart

* Add items to cart
* Display selected items
* Calculate total amount
* Place order option

## How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/Nayana1427/luxury-hotel-dining.git
```

2. Open the project in VS Code.

3. Install the Live Server extension.

4. Open `index.html`.

5. Click **Open with Live Server**.
